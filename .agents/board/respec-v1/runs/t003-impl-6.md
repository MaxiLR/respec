## Concerns

- Folders taken over by an earlier respec version, or taken over with no backup run (no folder existed for any target in that switch), have no takeover record. After a rebuild those folders are `takeover_unknown`, so a bare restore refuses until a run is named.
- The rebuild takes the latest takeover record per target, but only for folders that still hold respec links. A target that was released and never taken over again is therefore not re-owned from an old record.
