## Concerns

- `sync.py` calls the private `switch._plan`, so it does not duplicate the install plan. A public alias in `switch.py` would be cleaner, but `switch.py` was left alone while ticket 009 is in flight.
- Check updates and Add from git block the UI while git runs. They are fast over `file://`, but a slow network freezes the TUI until git returns. No worker thread was added.
- The editor has no remove-skill or layer on/off controls. They are outside the acceptance criteria, and the CLI still covers them.
- Builtin layer titles show the full built-in description, which wraps to two lines.
