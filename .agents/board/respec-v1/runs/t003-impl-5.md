## Concerns

- A rebuilt state records no takeover backups: `backup` is null, because takeover runs cannot be told apart from adopt runs by their layout. A later `respec restore` with no argument releases the folders without putting a backup back. The message points at `respec restore --list`, and the user can then name a run.
- Copies that respec installed cannot be recognised after a rebuild. They become unknown entries, which are backed up before they are removed.
