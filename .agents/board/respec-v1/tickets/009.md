## Goal

Global section and shipped agent skills.

## Acceptance criteria

- `~/.respec/config.yaml` global section lists items that survive every switch; they are installed only into the active profile's targets and are never removed by a switch.
- Ship `respec` skill (CLI usage, `profile.yaml` schema, layers, sources, adopt flow, hook-scope rule for the next phase) and `profile-maker` skill (guided interview producing a profile via CLI commands, rejecting project-scoped content such as component libraries).
- Shipped skills are in the global section by default; a profile can opt out with `system: false`.

## Testing seam

Switch between profiles with different targets; assert global items present only in active targets. Skill content reviewed against the actual CLI (commands named in skills exist; checked by a test that runs each documented command's `--help`).
