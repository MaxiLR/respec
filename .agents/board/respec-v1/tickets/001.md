## Goal

Usable package skeleton: `respec profile new|list|show` with a validated `profile.yaml`, the target registry, and `--json` output.

## Acceptance criteria

- Python package `respec` (Typer CLI, entry point `respec`), Black-formatted, pytest suite, uv-managed.
- Target registry data file with `claude-code` (`~/.claude/skills`), `agents` (`~/.agents/skills`), `oh-my-pi` (`~/.omp/agent/skills`), shaped after skills.sh `src/agents.ts` (name, display name, global skills dir).
- `RESPEC_HOME` relocates `~/.respec`; target dirs resolve against an overridable home (env or option) so tests never touch the real home.
- `respec profile new <name> --target <t>...` creates `profiles/<name>/profile.yaml` and `skills/`; unknown targets and duplicate names are rejected with clear errors.
- `profile list` / `profile show <name>` print human output and `--json`.
- `profile.yaml` schema loader validates targets and skill entries (`enabled`, optional `source`); invalid files produce actionable errors.

## Testing seam

CLI invoked against temporary `RESPEC_HOME` and home; assert on files created and `--json` output.

## Exclusions

Activation, layers, sources, TUI.

## Context

Spec `respec-v1` decisions 1, 2, 13, 14 and proposed defaults.
