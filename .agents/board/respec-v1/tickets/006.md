## Goal

Manage items in a profile from a local path: `add`, `remove`, `enable`, `disable`.

## Acceptance criteria

- `respec add <local-path> [-p profile]` copies a skill folder (must contain `SKILL.md`) into the profile; default profile is the active one.
- `remove`, `enable`, `disable` update `profile.yaml`; when the profile is active, target folders are refreshed immediately (links added/removed).
- Disabled items keep their files and metadata.
- All commands support `--json`.

## Testing seam

CLI against temp home; assert profile folder, `profile.yaml`, and target links before/after.

## Exclusions

Remote sources (007), layers (008).

## Context

Spec decisions 8 (local part), 9.
