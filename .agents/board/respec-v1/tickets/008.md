## Goal

Layers.

## Acceptance criteria

- Built-in layers `design-principles` and `output-style`, both exclusive, with shipped descriptions (design-principles: principles only, never component libraries or project tokens). Each can be turned off per profile.
- Custom layers: name, `exclusive`, `description`; CLI `respec layer add|rm|list|show` and `respec layer use <layer> <item>` / add item to layer.
- Exclusive layer allows at most one enabled item; enabling another disables the previous one. Additive layers can be enabled/disabled as a group.
- Layers never change install locations. Items outside layers are additive. With layers turned off, exclusivity lapses.
- `output-style` exists but accepts no items until output styles are supported (clear message).
