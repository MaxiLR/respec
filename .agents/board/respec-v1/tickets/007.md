## Goal

Git sources and explicit updates.

## Acceptance criteria

- `respec add <owner/repo>[#path]` / git URL fetches the skill(s) into the profile and records source repo, path, ref and resolved commit.
- `respec update --check` reports which sourced items have newer upstream commits; `respec update [item]` applies, refreshing links if active. Items without a source never change. Local edits to a sourced item are detected and require confirmation before overwrite.
- `respec profile install <repo>` copies a whole profile once (modpack-style); afterwards it is owned locally, with its items keeping their own sources.

## Testing seam

Local bare git repos via `file://`; no network in tests.
