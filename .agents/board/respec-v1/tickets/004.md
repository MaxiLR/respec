## Goal

Detect unknown entries in owned folders and let the user adopt them.

## Acceptance criteria

- Entries in an owned target folder that respec did not create are reported by `status` (and `--json`).
- Before a switch, unknown entries trigger a prompt per entry: add to profile (copied into the profile folder, then managed), back up and remove (to `backups/`), or keep unmanaged. Non-interactive runs require an explicit flag/policy and never delete silently.
- `respec adopt` resolves unknown entries outside of a switch, with `--json` and per-entry flags for agents.
- Nothing is removed without being adopted or backed up.

## Testing seam

Drop a foreign skill folder into a fake target after activation; assert report, each choice's filesystem result.

## Exclusions

TUI prompt (010).
